STDU 羽毛球智能预约助手（测试版）
====================================

一、重要说明
本项目目前是测试项目，不是已经验证的独立 EXE。为减少手动操作，安装依赖.bat 已改为自动检查并下载 Python 3.12.10（如电脑没有），安装到当前 Windows 用户目录，然后安装 Playwright、PyInstaller 和 Chromium。用户不需要事先安装或手动配置 Python，但首次运行需要联网下载运行环境和浏览器组件。

二、网页结构依据
- 场地列：.venue-column
- 场地名称：.venue-name
- 时间轴：.time-cell .time-label
- 预约时段：.slot.matrix-slot
- 绿色可约：free，且文字为“可约”
- 蓝色已选：selected，且文字为“已选”
- 已约：booked
- 锁定：locked

三、使用步骤
1. 将 ZIP 解压到普通文件夹，不要直接在压缩包内运行。
2. 电脑保持联网，双击“安装依赖.bat”。首次运行会自动下载并安装 Python 运行环境、程序依赖和 Chromium 浏览器，过程可能需要几分钟。
3. 安装完成后，双击“运行程序.bat”。
4. 点击“打开学校预约网页”，在打开的浏览器中登录，并手动切换到目标预约日期。
5. 在助手窗口填写预约日期、场地、开始时间、结束时间和自动执行日期/时间。
6. 勾选“我已在学校网页中登录，并手动切换到上面填写的预约日期”，点击“开始定时预约”。等待期间不要关闭程序或浏览器。

四、预约限制与安全
- 每个时段30分钟，最多选择4个时段（2小时）。
- 只尝试选择同时满足 free 类和“可约”文字的时段；点击后检查是否变成 selected / “已选”。
- 页面日期控件结构尚未确认，需要用户先在浏览器中手动切换到目标日期。
- 提交后若没有明确成功提示，请人工核对订单记录，不要重复提交。
- 定时执行期间，电脑必须开机、程序和浏览器保持运行、网络正常且账号保持登录。
- 请勿向任何人发送学校账号密码、Cookie、验证码或浏览器用户数据目录。

五、打包为 EXE
在完成自动环境准备后，双击“打包成EXE.bat”。EXE 会生成在 dist 文件夹。此打包过程仍需要在 Windows 电脑上实际执行和测试；不能保证在未经测试前可直接预约成功。
